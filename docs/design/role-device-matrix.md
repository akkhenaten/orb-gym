# Role and device contract

All cells are intended availability, not tested device results. Actual grants, sensitive fields and limited-account gates still apply.

| Journey/context | Desktop | Tablet/iPad including landscape | Mobile | Scope exception |
|---|---|---|---|---|
| Owner/management | Left gym tree, dense portfolio/calendar/reports | Bottom nav, panes by available inner width | Bottom nav, agenda/list and full-route approvals | Sensitive actions require delegated grant and assurance, not owner-labelled UI alone |
| Manager/supervisor | Assigned gyms, operational modules, rota/HR as granted | Bottom nav; task/rota panes adapt | Bottom nav; same permitted actions via More | No extra gym or self-escalated permission |
| Reception | Scan/ID card and till comparison panes | Bottom nav; camera and scanner fallback | Bottom nav; scan and basket steps | Shared-screen identity projection excludes private HR/health |
| Cleaner/operative | Own shifts/job sheets, evidence | Bottom nav; task panes/tab fallback | Bottom nav; Details/Activity/Records | No broad finance/member directory |
| Employed coach | Assigned PT/client/register and staff tools | Bottom nav; register and agenda | Bottom nav; attendance/PT/pass support | Customer prices and wages distinct |
| Rental coach | Own agreement/rent and allowed classes | Bottom nav; own scoped records | Bottom nav; own class register | No employed HR/CRM scope inferred |
| Active member | Member shell; classes/profile/bookings | Bottom nav; member-first touch layout | Bottom nav; QR always reachable | Entitlements differ single/all gyms |
| Pending/PT-only/trial | Limited shell and checklist/appointments/own records | Bottom nav; limited tools | Bottom nav; applicable pass only after gate | No full membership merely by signup |
| Guardian/dependent | Member shell with dependent selector | Bottom nav; granted family actions | Bottom nav; selector stays explicit | Payer/guardian/collector rights separate |
| Vendor/contractor | Assigned Jobs/Visits/Updates/Account | Bottom nav; job panes when space permits | Bottom nav; item tabs/evidence | Contractor cannot approve own quote or manager verification |
| Platform support | Separate audited workspace-scoped admin context | Responsive admin, bottom compact nav | Responsive critical support actions | Auth assurance and approved support scope; no silent customer impersonation |

Critical matrices for final implementation multiply screen/role by light/dark, five selectable presets, input method and material states; use shared component checks to reduce repetition, record exceptions rather than claiming every combination from one screenshot.
