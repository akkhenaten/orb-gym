# Company and Gym Branding

Settled requirement: the company using Orb Gym can select the full UI direction and add its own logo and colours in Company Settings → Style & Branding. This is runtime workspace configuration, not a separate code fork for each customer.

The five selectable presets are Orb Gym Basic 01, Flat Studio 02, Minimal Editorial 03, Soft Glass 04 and Performance Console 05. Each changes the full component/layout treatment, with light/dark counterparts. Soft Glass 04 is the earlier iOS-inspired Soft direction, not a duplicate preset. Neumorphic 06 is defined but deferred and is not a selectable option.

## Configuration lifecycle

Start with Orb Gym Basic and the supplied Orb Gym identity. Authorised company users select a preset, upload logo/icon and configure permitted colours/fonts/surfaces. Preview representative roles/devices/modes, validate, save and publish the appearance draft; deliberately activate white labelling separately to activate company identity. Upload alone does not activate it. Permit authorised gym overrides and reset-to-inheritance. Record who published each version and support rollback/disable without deleting historical drafts/documents.

Style selection and white-label activation are distinct settings; the builder must make their preview/publication interaction explicit rather than switch logos unexpectedly. Personal light/dark/system preference remains independent. Inheritance: platform default → published company configuration → permitted gym override, with per-user appearance mode applied separately.

## Propagation

Use one published brand source for app shells, member/vendor portals, public pages, documents/communications and new receipts. Billing identity is a separate legal/entity setting. Issued/signed records freeze the data/template/brand version originally used. Live public gym/coach projections update from approved records, not duplicated page copy.

The assistant stays named Orb and uses the approved company icon after activation; fall back to the Orb Gym icon until a suitable company mark is approved. A different gym logo does not silently rename Orb. Every app and public page retains the exact footer **Orb Gym - powered by orbsolutions.co.uk**.

No configuration can remove permission enforcement, expose private data or publish inaccessible controls/contrast. Assets are validated/versioned with ownership. Private guidelines and internal uploads never become publicly downloadable merely because colours were extracted. Reverse/default icon derivatives still need approval. See ../design-and-token-deliverables.md and ../modules/08-design-branding-documents-pages.md for the complete rules.


The [0.35 UI direction contract](ui-direction-settings.md) details the five-choice selector (Neumorphic06 deferred), scoped preview/save/publish/rollback, profile effects reduction and expanded component rules. Style publication works independently of white-label activation.
