# Runtime-Public Assets

Only deliberately public static assets belong here. The supplied Orb Gym master logo is kept at assets/orb-gym-logo.png. The chosen framework/build process may publish approved derivatives from that master; avoid manually maintaining divergent copies.

Company/gym uploaded logos, guidelines, staff photos and generated documents are runtime records with ownership/access/publication state. Keep originals and private evidence outside this directory. Publish only validated approved derivatives/content. PAR-Q, HR, receipts, signed agreements and operational attachments must never become static public files through a reusable upload component.

No public application bundle has been generated. The final asset URLs/cache rules belong in the implementation plan for the selected framework and hosting project.
